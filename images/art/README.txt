originals/   Full-size files from Susan's Padlet export, in their board sections. Not used by the site directly.
*.jpg        Web copies (2000px long side) used by the slideshow and the full-screen viewer.
thumbs/      900px copies used in the grids. Same file names as the web copies.

To add a painting: put the original in originals/, make a 2000px copy here and a 900px copy in thumbs/
with the same name, then add an entry to assets/artworks.js.
